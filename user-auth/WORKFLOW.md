# 시스템 워크플로우 및 역할

## 1. 회원가입 및 인증

- **사용자**는 `/api/auth/register`로 회원가입 요청
- 이메일/비밀번호 등 정보 저장, 중복 체크
- 회원가입 성공 시 로그인 가능
- **로그인**: `/api/auth/login` → JWT 토큰 발급
- 토큰 기반 인증으로 API 접근

## 2. 사용자 관리

- **일반 사용자**: 자신의 정보 조회/수정, 탈퇴 가능
- **관리자**: `/api/users`로 전체 사용자 목록, 상세, 상태(정지/해제) 변경
- **탈퇴 사유 통계**: `/api/users/withdrawal-reasons`로 집계

## 3. 관리자 관리

- **최고 관리자**: 관리자 초대 코드 생성(`/api/auth/invite-code/generate`)
- **신규 관리자**: 초대 코드로 가입, 역할 부여
- **관리자 역할/상태 변경**: `/api/admins/{admin_id}/role` 등

## 4. 게시물 관리

- **사용자**: 게시물 작성, 조회, 수정, 삭제
- **관리자**: `/api/posts`로 전체 게시물 목록, 상세, 상태(숨김/정지 등) 변경
- **신고 게시물 검토**: `/api/posts/pending-reviews`로 대기 목록 확인
- **통계**: `/api/posts/statistics`로 집계

## 5. 신고 처리

- **사용자**: 게시물/사용자/채팅 신고 가능
- **관리자**: `/api/reports/*`로 신고 목록, 상세, 상태/처리(조치, 알림, 정지 등) 변경
- **신고 처리**: 조치 내역 기록, 관련자 알림

## 6. 알림 시스템

- **관리자**: 알림 템플릿 생성/수정(`/api/notifications/templates`)
- **알림 발송**: `/api/notifications/send`로 대상자에게 알림
- **발송 내역/통계**: `/api/notifications/history`로 확인

## 7. 해시태그 관리

- **사용자**: 게시물에 해시태그 추가
- **관리자**: `/api/hashtags`로 해시태그 목록, 상세, 상태(차단/추천 등) 변경
- **통계/워드클라우드**: `/api/hashtags/statistics`, `/api/hashtags/wordcloud`

## 8. 문의/고객센터

- **사용자**: 문의 등록
- **관리자**: `/api/admins/inquiries`로 문의 목록, 상세, 상태 변경, 답변 등록

## 9. Firestore/외부 DB 연동

- **관리자**: Firestore 컬렉션/문서/필드 직접 조회(`/api/firestore/*`)

---

## 역할별 주요 권한

### 일반 사용자

- 회원가입/로그인/로그아웃
- 게시물 작성/수정/삭제/신고
- 해시태그 사용
- 문의 등록

### 관리자

- 사용자/게시물/신고/해시태그/문의/알림 전체 관리
- 관리자 초대/역할 변경
- 통계/대시보드 확인
- Firestore 직접 조회

### 시스템

- JWT 토큰 발급/검증
- 비밀번호 암호화
- 알림 발송 자동화
- 통계 집계 및 데이터 정합성 유지

---

## 전체 흐름 요약

1. **회원가입/로그인 → JWT 발급 → 인증된 API 접근**
2. **사용자/게시물/신고/해시태그/문의 등 CRUD 및 상태 변경**
3. **관리자 권한으로 전체 데이터 관리 및 통계/대시보드 확인**
4. **알림/이메일/Firestore 등 외부 서비스와 연동**
